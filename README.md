# C 习题知识点总结

本 README 汇总了当前工作区下各个 C 源文件的知识点，按目录和文件逐条说明，方便复习与学习。


## 总体说明

- 所有主要目录均为练习题或示例程序。
- `bin/` 目录通常存放对应目录下 `.c` 源文件的可执行结果。
- 主要覆盖的知识点包括：输入/输出、条件判断、循环、数组、字符串、函数返回、几何计算、结构体/typedef、数学库、控制流、字符串处理等。


## one

该目录主要是基础语句、输入输出、分支判断与几何计算练习。

- `one/ah.c`：`main`、`scanf`、`printf`、条件判断、分支输出。
- `one/area.c`：几何面积计算、数学库、输入输出、分支判断。
- `one/d.c`：基础 `main` 函数、分支判断、输出。
- `one/image.c`：输出、循环、基本控制流。
- `one/price.c`：价格或费用计算、输入输出、分支、几何相关逻辑。
- `one/radius.c`：圆形半径相关计算、输入输出、分支、几何公式。
- `one/rectangle.c`：矩形几何计算、输入输出。
- `one/start.c`：字符串输入、数组表示字符、字符串逆序输出。
- `one/t.c`：字符串处理、输入输出。
- `one/test.c`：简单输出示例。
- `one/triangle.c`：三角形几何计算、输入输出、分支判断。
